# 🦅 FeatherFury: Vengeance

لعبة أركيد ملحمية مطورة بأحدث تقنيات الويب (HTML5 Canvas + Web Audio API). انطلق في رحلة خطيرة عبر عوالم مظلمة لمواجهة ملك الغربان، واجمع العملات الذهبية لفتح طيور أسطورية جديدة! 

---

## ✨ ميزات وإضافات الإصدار (V1.0):

### 🌍 1. عوالم اللعبة والقائمة الرئيسية (Carousel UI):
- **العالم الأول: الأطلال البركانية (Ruins)** جاهز للعب بخلفيات تفاعلية (نهار، غروب، مطر، وعواصف).
- واجهة اختيار العوالم (Carousel) قابلة للتوسع لإضافة عوالم جديدة مستقبلاً.
- نظام تقييم بالنجوم (1 إلى 3 نجوم) يعتمد على أدائك في المرحلة.

### 👑 2. معركة الزعيم (Boss Fight):
- بعد تخطي مرحلتين في عالم الأطلال، يتغير لون السماء وتبدأ العاصفة ليظهر **"ملك الغربان" (Crow King)**.
- زعيم يمتلك ذكاءً اصطناعياً: يطلق ريشاً دموياً، ويقوم بهجوم اندفاعي (Dash) مميت.
- عند هزيمته، ستشاهد شاشة سينمائية لإنقاذ "البومة الحكيمة"!

### 🪙 3. نظام الكوينز ومتجر السكنات:
- متجر متكامل يحتوي على 5 طيور (حمامة، صقر، فينيق، سايبورغ).
- حفظ تلقائي (`localStorage`) للكوينز المجمعة والسكور العالي.

### 🪶 4. عقبات بركانية وأعداء:
- أعمدة صخرية بركانية مصممة بنظام (9-Slice Vector Canvas) للحفاظ على جودة دقة الشاشة (HD).
- غربان طائرة تقطع الشاشة بشكل عشوائي وتتطلب رد فعل سريع.
- قوة خاصة (Power Orb): اجمع الأجرام السماوية الزرقاء لإطلاق ليزر تدميري يمسح الأعداء والزعيم!

### 🌐 5. دعم اللغات (I18N):
- اللعبة تدعم اللغتين **العربية** و **الإنجليزية** بالكامل (القوائم، الحوارات السينمائية، والإعدادات).

---

## 🎮 التحكم:
- **الكمبيوتر**: زر **المسافة (Space)**، زر **↑**، زر **W**، أو النقر بالماوس.
- **الموبايل والشاشات اللمسية**: لمس الشاشة في أي مكان.

---

> **مخطط التطوير الحالي والأنظمة المعتمدة:** راجع [`GAME_PLAN.md`](GAME_PLAN.md) قبل أي تعديل، خصوصًا الأنظمة المعلّمة **APPROVED / LOCKED** حتى لا نعيد تجربة تقنيات جديدة بعد اعتماد الحل.
