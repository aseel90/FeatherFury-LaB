# Feather Fury

Feather Fury هي لعبة أركيد/مغامرة عمودية مبنية على HTML5 Canvas مع قصة، عوالم متتابعة، زعماء، شخصيات وقدرات، عملات، Fever Mode، متجر، إحياء، إعدادات وحفظ محلي.

> **المرجع التقني الأساسي:** [`FEATHER_FURY_GAME_SPEC.md`](FEATHER_FURY_GAME_SPEC.md)  
> **قواعد التطوير والرجوع الآمن:** [`DEVELOPMENT_RULES.md`](DEVELOPMENT_RULES.md)  
> **اتجاهات التصميم والأنظمة المعتمدة:** [`GAME_PLAN.md`](GAME_PLAN.md)  
> **ملخص المالكين النشطين:** [`RUNTIME_ACTIVE.md`](RUNTIME_ACTIVE.md)

## الحالة الحالية

| العالم | الحالة | الزعيم | الحارس / الخاتمة |
|---|---|---|---|
| W1 — Cursed Woods | يعمل / مجمد للميزات الجديدة | Crow King | Owl Guardian |
| W2 — Frostbite Peaks | يعمل / مفتوح لإصلاحات وصقل محدد | Ice Emperor | Mountain Eagle |
| W3 — Storm Spire | يعمل / مفتوح لإصلاحات وصقل محدد | Lord Voltbat | Phoenix Guardian |
| W4 — Volcanic Valley | قادم لاحقًا | — | — |

يوجد كذلك Endless Mode منفصل عن تقدم الحملة.

## أنظمة اللعب الحالية

- تحكم باللمس/الماوس ولوحة المفاتيح.
- مراحل طيران وعقبات وأعداء وتدرج صعوبة.
- Fever Mode وعملات وقدرات شخصيات.
- معارك زعماء متعددة المراحل.
- حوارات وقصص وخواتيم خاصة بالعوالم.
- متجر شخصيات/سكنات مع حفظ محلي.
- Revive باستخدام العملات.
- دعم العربية والإنجليزية.
- واجهة اختيار عالم، HUD، Pause، Settings، Shop ونتائج.
- Leaderboard الحالي محلي/تجريبي وليس Backend عالميًا حقيقيًا.

## ملاحظة معمارية مهمة

نسخة LAB الحالية تعمل ومحمية بفحوصات تلقائية، لكن تاريخ المشروع يحتوي على طبقات patches كثيرة وبعض الملفات القديمة المتقاعدة ما زالت موجودة في المستودع لأغراض الرجوع. وجود الملف **لا يعني أنه نشط**.

قبل أي تعديل يجب التحقق من:

1. `FEATHER_FURY_GAME_SPEC.md` لمعرفة المالك الفعلي للنظام وترتيب التشغيل.
2. `game.js` لمعرفة `ACTIVE_PATCHES` و`RETIRED_PATCHES` الحقيقية.
3. `DEVELOPMENT_RULES.md` لقواعد branch/rollback والتحقق.

لا تُعد أي ملف قديم إلى التشغيل اعتمادًا على اسمه أو رقم نسخته فقط.

## الاختبارات والنشر

GitHub Actions يحتوي على:

- فحص syntax وسلامة ملفات التشغيل ومنع التداخل بين active/retired patches.
- حماية من تقليص/بتر الملفات الأساسية.
- نشر GitHub Pages للـLAB.
- Live smoke test على Chromium وWebKit بحجم هاتف، يتحقق من: الإقلاع → القائمة → PLAY → PLAYING → HUD → Pause.

تفاصيل التغطية الحالية وما لم تتم تغطيته بعد موجودة في `FEATHER_FURY_GAME_SPEC.md`.

## Android / Google Play

الهدف النهائي هو Android/Google Play عبر Capacitor/AAB. معاينة الويب وسيلة تطوير واختبار، وليست سببًا للاعتماد الدائم على خدمات خارجية وقت التشغيل. قبل نسخة Android النهائية يجب إزالة أي اعتماد Runtime خارجي وتثبيت كل الكود والأصول داخل الحزمة.

## قاعدة المشروع

عند إصلاح مشكلة صغيرة: أصلح **مالك النظام الحالي** فقط، لا تضف طبقة patch جديدة فوق نظام مستقر إلا عند الضرورة الموثقة، ولا تغيّر نظامًا معتمدًا أثناء العمل على نظام آخر.
